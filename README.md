## 1. Overview
Smart Escape is an interactive, browser-based evacuation route simulator created for AI DevFest 2026. It calculates the lowest-cost escape path from a selected starting location to an open exit using dynamic graph pathfinding algorithms. When building conditions change (e.g., corridors blocked, rooms unavailable, or exits closed), the application dynamically recalculates an optimal route or clearly informs the user if no viable path exists.
